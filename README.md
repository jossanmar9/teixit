# Teixit

**Gestió lliure per a associacions**

Teixit és un projecte de programari lliure pensat per facilitar la gestió interna d'associacions i entitats sense ànim de lucre.

La idea és partir d'un nucli comú de gestió associativa i, amb el temps, adaptar-lo a diferents tipus d'entitats: associacions culturals, clubs esportius, AMPA/AFA, falles, gaiates, fogueres, colles i altres organitzacions semblants.

## Principis del projecte

- Programari lliure sota la llicència **GNU AGPL v3 o posterior (AGPL-3.0-or-later)**.
- Funcionament local o autohostejable.
- Sense subscripcions obligatòries.
- Sense telemetria.
- Sense recopilació de dades per part del projecte.
- Les dades de cada associació són seues i es mantenen sota el seu control.

## Estat

Projecte en fase inicial de definició.

De moment, este repositori existeix únicament per reservar el nom i deixar documentada la idea general. Encara no hi ha desenvolupament actiu ni una arquitectura decidida.

## Idea de base

El nucli comú podria cobrir àrees com:

- persones i socis,
- junta directiva,
- actes i documents,
- quotes, rebuts i domiciliacions,
- llibre de caixa,
- comunicacions,
- usuaris i permisos,
- còpies de seguretat.

A partir d'ací, cada tipus d'associació podria incorporar mòduls específics segons les seues necessitats.
